# Noor Quran v0.5.0

- Added optional quiet hours for reminders, defaulting to 23:00–07:00.
- Reminder preview bypasses quiet hours so the user can test sound instantly.
- Reminder screen now restores the currently saved zikr, interval and mode.
- Added a clear status card showing whether reminders are active and the selected sound/quiet-hours configuration.
- Kept sound, vibration-only and silent notification modes from v0.4.0.
- Kept reminder rescheduling after device reboot.
