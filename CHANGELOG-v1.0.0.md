# Noor Quran 1.0.0 — Final source candidate

- Complete Quran reading from bundled Uthmani text.
- Offline Al-Muyassar tafsir.
- Quran search and resume last reading position.
- Multi-reciter audio streaming and offline ayah/surah download cache.
- Hadith collection with sources.
- Daily adhkar section (morning/evening/sleep/wake/tasbeeh/salawat).
- Electronic tasbeeh counter with persistent count and 33/100/1000 goals.
- Qibla compass using device location + accelerometer/magnetometer sensors; no external Qibla API.
- Enhanced dhikr reminders: custom sound, vibration-only, silent mode, preview, quiet hours, reboot restore.
- Android 13+ notification permission handling.
- Android location permissions for Qibla.
- Gradle/Android project structure and GitHub Actions APK build workflow.
- Version promoted to 1.0.0 (versionCode 10).
